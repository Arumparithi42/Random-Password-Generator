# Random Password Generator

A simple Python command-line program that generates random passwords containing lowercase letters, uppercase letters, numbers, and symbols.

## Requirements

- Python 3

## Usage

1. Run the program:

   ```bash
   python PasswordGenerator.py
   ```

2. Enter a password length of at least 10 characters when prompted.

The generated password is printed in the terminal.

## Notes

- The password includes at least one lowercase letter, uppercase letter, digit, and symbol.
- The program keeps asking until a valid length is provided.
